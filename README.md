# 📊 E-Commerce Sales & Profitability Dashboard | Power BI

## 📌 Project Overview
This project presents an interactive E-Commerce Sales Dashboard developed using Microsoft Power BI.

The objective is to analyze sales performance and profitability through interactive visualizations and business KPIs.

## 🎯 Key Performance Indicators
- Total Sales
- Total Quantity
- Total Profit
- Average Order Value (AOV)

## 📈 Dashboard Visualizations
- Profit Analysis by State
- Quantity Distribution by Product Category
- Monthly Profit Trends
- Payment Mode Analysis
- Customer-wise Sales Performance
- Profit Analysis by Sub-Category

## 🎛️ Interactive Features
- State-wise Slicer
- Quarter-wise Slicer

These slicers allow users to explore sales performance across different states and quarters.

## 📂 Data Source
- Data Format: CSV
- Tool Used for Analysis: Microsoft Power BI

## 🛠️ Tools & Skills
- Microsoft Power BI
- DAX
- Data Visualization
- Business Analysis
- Interactive Dashboard Development

## 🧮 KPI Calculation
**Average Order Value (AOV)**

AOV = Total Amount / Total Orders
